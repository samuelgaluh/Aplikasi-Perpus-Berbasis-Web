# PerpusCihuy - Library Management System

## Description
PerpusCihuy is a web-based library management system built with PHP that helps librarians and administrators manage books, members, borrowing transactions, and other library operations efficiently.

## Features
- Book management (add, edit, delete, search)
- Member management
- Borrowing and returning books
- Fine calculation for late returns
- Reports generation
- User authentication and authorization

## Requirements
- PHP 7.4 or higher
- MySQL/MariaDB
- Apache/Nginx web server
- XAMPP (recommended for local development)
